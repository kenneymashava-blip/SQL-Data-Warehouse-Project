# Data Warehouse and Analystics project

Welcome to the **data warehouse and Analytics project** repository!

This project is about building a data warehouse with SQL Server Management Studio, including ETL, Data Modeling and Data Analytics.
The project demonstrates a comprehensive data warehousing and analytics solution, through building a data warehouse
to generate actionable insights. 

# Project Overview

### This project showcases: 
- **Data Architecture:** Design Data Warehouse using the **Medallion Architecture** *Bronze, Silver and Gold layers* Architecture.
- **ETL Pipelines:** Data extraxtion ,transformation and loading from source systems into Data Warehouse.
- **Data Modelling** Developing business ready datasets: Dimension and Fact Views geared towards direct queries for Data Analytics and Reporting.
- **Analytics and Reporting** Create dashboards and SQL-based reports for actionable business insights.
